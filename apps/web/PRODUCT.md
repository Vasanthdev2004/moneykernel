# Product

## Platform

web

## Users and purpose

MoneyKernel's operator reviews AI agents' trade requests, grants bounded leases, and approves exact proposals. The deterministic backend owns financial authority. This web app helps the operator understand the account and act on the next decision.

## Capabilities and constraints

Preserve approval confirmation, proposal expiry, stop/resume, unknown-state warnings, agent/lease administration, conflicts, commands, incidents, receipts, exports and the event stream. Financial values come from the kernel and remain exact decimal strings. Never invent performance data or change policy to make the demonstration easier.

The reviewed prototype uses synthetic REPLAY data and paper execution. Integration limits remain visible and inspectable. Full P0 qualification and public deployment are not implied by the interface. Product truth and evidence remain in the root PRD, README and evidence documents.

## User direction

The owner rejected the crowded cockpit layout and chose a clean light dashboard with breathing room. They then requested a UI library and both light and dark modes. Use light by default and remember an explicit theme preference. Group operational details by task instead of showing every module simultaneously.
